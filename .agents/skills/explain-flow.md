Explain how data flows through the file the user points at.

1. Give a numbered walk-through, one short line per step, in execution order.
2. Name every file it reads, every request it makes, and what it puts on screen.
3. Finish with a Mermaid flowchart saved as an artifact so it can be rendered
   in the terminal.

Do not edit any files.
